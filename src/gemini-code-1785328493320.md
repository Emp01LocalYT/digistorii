### Processing Logic

1. **Handle Split Payments**: Group transactions by `payment_mode_id` and calculate `SUM(amount)` for the selected date range. Do **not** deduplicate by `sales_id` since multiple rows under one `sales_id` represent legitimate split payments.
2. **Total Calculation**: Calculate `Grand Total = SUM(all mode totals)` for display in the center/header.

## 4. Technical Implementation Prompt

```typescript
// Example State & Filtering Interface
interface DateFilter {
  type: 'today' | 'monthly' | 'yearly' | 'custom';
  startDate?: string;
  endDate?: string;
}

// Data Transformation Routine
function aggregatePaymentData(payments: SalesPayment[], filter: DateFilter) {
  const filtered = filterPaymentsByDate(payments, filter);
  
  const totalsByMode = filtered.reduce((acc, curr) => {
    const mode = curr.payment_mode_id;
    acc[mode] = (acc[mode] || 0) + Number(curr.amount);
    return acc;
  }, {} as Record<number, number>);

  const grandTotal = Object.values(totalsByMode).reduce((sum, val) => sum + val, 0);

  return { totalsByMode, grandTotal };
}

```
